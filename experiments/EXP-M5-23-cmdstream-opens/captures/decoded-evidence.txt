TASK 3 — INTRA-TILE MORTON BYTE ORDER   [BLOCKED on M5 — root cause characterised]
================================================================================
Goal: byte-verify the within-tile twiddle by writing texel(x,y)=(y<<16)|x and reading the raw
backing. On M5 the raw twiddled backing is NOT CPU-observable through any available route:
  (a) iotrace sel-9 BO capture: a STANDALONE StorageModeShared texture backing (0x28000, uncompressed
      with ShaderWrite) is NOT registered via resource-map selector 9 (unlike A18/EXP-0017).
      Grep of every captured BO for the raw value 0x00020003 (texel(3,2)) = 0 occurrences, for
      draw-store AND compute-store.  (Only 2 sel-5 pages + buffers/heaps are captured.)
  (b) Heap-placed texture: heap backing IS a sel-9 BO and IS captured (va10000040000 sz0x2c000),
      but M5 stores heap textures LOSSLESS-COMPRESSED even with ShaderWrite (texSizeInHeap 0x24800 =
      image 0x24000 + 0x800 aux; content is the HW compression codec, e.g. repeating 0x4c-byte
      blocks "04000e25 fc040000 ffffffff ...", NOT the raw Morton curve).
  (c) Self-process VM scan (texscan.m; reading OUR OWN texture's data — clean-room OK): the full set
      of 36864 distinct texel values never appears contiguously in ANY CPU-readable region
      (best window: RW 383/36864 distinct; incl. READ-only 3688/36864). getBytes returns correct
      texels (de-twiddle happens on a GPU/driver path), but the twiddled bytes never materialise in
      CPU-visible linear memory.
Consequence: the exact intra-tile permutation is not independently re-derived on M5. The ALLOCATION
model (tile edge T per bpp, page-granule G, mult-of-T padding, aux=numTexels/32) IS byte-for-byte
confirmed (EXP-M5-10) — a direct consequence of the tiled-Morton layout — so the Morton STRUCTURE is
strongly corroborated; the within-tile order remains inherited from A18 (docs/tiling/README.md 1.1).

  buf=2: +0x610=..01cd00  +0x618=..01ce00                                  (buf[0..1])

indirect form beyond 2 buffers — the inline-VA slot list simply extends. All STATUS=4.
