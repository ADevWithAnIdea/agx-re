# EXP-0220 — PRE-REGISTRATION (frozen before the first gated dispatch)

**Target:** Apple A18 Pro / **G17P** (`AGXAcceleratorG17P`, `applegpu_g17p`, 5 cores,
macOS 26.6, `Mac17,5`, Metal family Apple9) at `192.168.170.254`. **Nothing runs on the M4.**

**Clean-room category:** OWN-SHADER + HW-PROBE. Our own MSL carrier compiled through the
public runtime API; every executed instruction byte is generated by this experiment from
`db.json` rules. **No Apple binary is disassembled, decompiled or introspected.**

## 1. The question

`RE_EXPERIMENT_PROCESS_CORRECTIONS.md` **Gate D**:

> "To call an instruction compiler-usable, construct every required byte from documented
> rules, run the exact generated program, and compare complete state with a host prediction.
> The evidence record must identify every copied region and prove that no required
> instruction field came from a compiler-emitted donor."

and: *"A canonical recipe must cover the operand classes and context the compiler will
actually select."*

**Question.** Can a complete `falu2` and a complete `device_store` be constructed byte by
byte from documented rules, across the operand classes and contexts a compiler actually
selects, executed on G17P, and their COMPLETE observable state predicted in advance by a
host oracle — with **zero** fields taken from a compiler-emitted donor instruction?

## 2. Hypotheses and falsifiers

| # | Hypothesis | Refuter |
|---|---|---|
| H1 | Every field of `falu2` and `device_store` can be given a value derived from a documented rule; no program in the matrix contains a field tagged `COPIED` or `CARRIER`. | any case whose provenance ledger reports a non-zero `COPIED`/`CARRIER` count |
| H2 | `base_slot` can be determined by HARDWARE PROBE rather than read off a compiled instruction: exactly one slot value writes the buffer bound at index 0. | arm S0 finds zero, or more than one, slot writing a given buffer |
| H3 | For every gated (`predicted_bucket: exact`) case the host predicts EVERY touched byte of all three buffers exactly. | any `wrong` / `no_write` / `stray` / `unpredicted` byte in a gated case |
| H4 | For every `predicted_bucket: corrupt` case — values the documented model says corrupt — the observation is NOT exact. | a "corruptor" that delivers the correct answer refutes the model |
| H5 | The two pre-registered falsifiers (`predicted_bucket: refute`) FAIL. | if either matches, the comparator has no detection power and every arm is `carrier-undecidable` |
| H6 | Run 01 (canonical order) and run 02 (shuffled) produce byte-identical programs per case and identical per-case buckets. | any program-hash or bucket disagreement |

## 3. Independent / controlled variables

Independent: the case matrix in `harness/cases220.py` (24 arms, 1584 cases with hazards,
1573 without). Controlled and held fixed: carrier kernel, buffer contents, grid/threadgroup
(1/1), pinned `db.json`, pinned `isadb.py`, harness revision, poison word `0xDEADBEEF`.

## 4. Gate mapping

* **Gate A** — per case, per instruction: the bytes the caller asked for are the bytes at that
  offset in the dispatched program (`dispatched_bytes_verified` re-reads the spliced archive
  from disk), and an INDEPENDENT bit-extraction decode of those bytes (`decode_fields_as`,
  which does not use the length rule and is not `assemble`'s inverse-by-construction) returns
  the requested values. Recorded in `gate_a` and `under_test` on every record.
* **Gate B** — `ctl_baseline` (the full observation path fires: sentinel + 24 register slots),
  `ctl_move_*` (the observable moves when only the operand value changes), `ctl_norun` (with
  our bytes doing nothing the out buffer stays entirely poison). The observable NEVER co-varies
  with the field under test: the read-back plan is a fixed 24-register dump at fixed
  `idx_off`s, plus every byte of all three buffers.
* **Gate C** — every case carries a `predicted_bucket` chosen BEFORE the run
  (`exact` / `corrupt` / `refute` / `measure`) and a full host oracle; the observation is
  classified into `exact / wrong / no_write / stray / unpredicted / fault / hang /
  measurement_failure`.
* **Gate D** — the provenance ledger (`RULE` / `FREE` / `CARRIER` / `COPIED`) over every field
  of every instruction of every program, plus the enumerated copied-region list in §7.
* **Gate E** — two clean G17P runs, `run01` canonical order and `run02` shuffled
  (`--order shuffle --seed 220`), with `harness/quietsample.py` measuring the machine quiet
  for the duration and `recoveryCount` sampled before and after.

## 5. Stopping rule and hazard budget

Every finite domain in the matrix is swept densely (`falu2.dst` 16/16, `srcA_reg` 64/64,
`srcB_reg` 64/64, `opflags` 32/32, `mod_hi` 32/32 over two provenance classes, inline
immediate 64/64 × 2 signs × 2 ops, `device_store.addr_mode` 256/256 × 2 data-source classes,
`extmode` 252/256). **Hang budget: 12 per run**, after which the run stops and records why.
Declared hazards, dispatched only with `--hazard`: `index_reg` in {96,97,100,111,112,120,127}
(EXP-0141 faults) and `extmode` >= 252 (EXP-0112 records r126/r127 faulting).

## 6. Disclosed PRE-FREEZE PILOT

Pilots `p01`..`p08` and `harness/diag220.py` ran under `work/pilot/` on the neo BEFORE this
document was frozen, and their findings are folded into the models below. They are disclosed,
not evidence: every claim they suggested is re-measured inside the frozen matrix. What they
changed, each one a correction to a previously documented rule:

1. **`falu2` `opflags` bit1 is OPERAND-CLASS DEPENDENT.** With a GPR `srcB` it is the
   documented release-src1 lifetime bit; with a non-GPR inline immediate it **negates the
   immediate**, XORing with `srcB_neg` (diagnostic D7, four instructions differing only in
   those two bits; D8 is the paired GPR control). EXP-0167's committed
   `INLINE_NEG0_SIGN = -1` is that experiment's always-set bit1 folded into a constant.
2. **`falu2.mod_hi` bit0 set => the destination is not written at all** (D9), and bits 2+3
   are an ACCEPT/FORWARD control for a device_load result that is still in flight: with a
   load immediately preceding, only `0xC` of {0,4,8,C,E} is exact; with one intervening
   instruction all five are (A13 pilot).
3. **`device_store` releases its index register** — it reads 0 afterwards, and a second store
   reusing it addresses with index 0 (D10/D11).
4. **A `device_store` whose index register is a live load result addresses with the STALE
   value**; one intervening instruction fixes it (D12).
5. **`device_store.addr_mode` bit1 is the store-side twin of `mod_hi` bits 2/3**: with a live
   load result as the store DATA, bit1 set forwards it; bit1 clear stores the stale register
   value AND DROPS THE LOAD (the destination register never receives it).
6. `mov_imm` immediates that do not tokenize as a 2-byte instruction are not only `imm7 == 12`
   (EXP-0140) but every `imm7 == 6 (mod 16)`; the seeds avoid all nine.
7. The b16 operand arm must not use the `(j+1)/4` codewords: their low half is all zero, so a
   b16 arm built on them reads 0.0 for both operands and passes by construction. Sixteen
   PACKED-HALF words were added for it.

## 7. THE COPIED-REGION LEDGER (Gate D's central requirement)

What is generated: **every byte of `_agc.main`** — the whole region is overwritten from offset
0 with bytes this experiment assembled from `db.json`, padded to the carrier length with
generated `mov_imm` words that run after `stop` and are never reached.

What is NOT generated, exhaustively:

| region | why it is not an instruction field | how it is obtained |
|---|---|---|
| the Metal binary-archive container, AIR, and metadata (buffer binding table, code length, threadgroup descriptor) | not instruction bytes; EXP-0220 documents the ISA, not the command stream | produced by compiling OUR OWN MSL carrier through the public runtime API |
| `base_slot` (a real instruction field) | **NOT taken from a donor**: EXP-0167 re-derived it by disassembling its own compiled carrier — honest, but that reads a required field off a compiler-emitted instruction | **arm S0 hardware probe**: sweep `base_slot` in a generated store and observe which bound buffer the write lands in |

`CARRIER` and `COPIED` are retained as ledger classes precisely so the record can prove they
are empty. **Expected: 0 of each, over every field of every instruction of every program.**

## 8. Frozen inputs

Hashes: `CAPTURE_CONTRACT.json`. Repo revision at pre-registration: recorded there.
Raw records are append-only; `raw/<run_id>/sweep.jsonl` is written one line per case and
flushed immediately.

## 9. What this experiment does NOT claim

* The `srcB` **uniform-register** operand class is dispatched but not predicted (8 cases,
  `measure`): seeding the uniform file is out of scope here.
* `opsel` 0,1,2,3,6,7 in the 6-byte form are recorded, not modelled.
* NaN payloads, overflow-to-infinity and denormal results are recorded, not claimed
  bit-for-bit against a host double.
* `extmode >= 128` (a data-register index >= 64) is recorded, not claimed.
* Threadgroup-space stores (`space` bit1) are recorded, not claimed.
* Nothing here is promoted into `docs/`, `PROVENANCE.md`, `tools/agx-isa/` or any label.
