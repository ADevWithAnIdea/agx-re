# EXP-0059 pre-registration — FALU2I semantic property vectors

Frozen before the first EXP-0059 analysis invocation. This is a repository-only
P0.6 audit on the Apple9 ISA database. It creates no hardware or A18 claim and
never opens an Apple binary, compiled Apple code, unknown BO, cache, or system
shader.

## Concrete gap

EXP-0046 showed that central synthesized vectors reached only 19 descriptors.
`falu2i` has existing own-shader / splice validation for the immediate form,
but its central tests cover only two positive constants. This experiment tests
the **declared semantic sub-schema** of that descriptor mechanically:

`dst`, `srcA_size`, `srcA_reg`, `opsel`, `imm_flag`, `imm_mant`, `imm_exp`, and
`imm_sign`.

It deliberately excludes `opflags`, `ctrl_lo`, and `mods`: they are modifier
bits whose full semantic/property meaning is not established by the existing
descriptor. The exclusion is an outcome, not an implicit default or compiler
permission.

## Frozen vector domain

The generator uses the bounded, independently meaningful edge/cross-product:

- `dst = {0, 1, 7, 15}` (the compact falu2 destination range);
- `srcA_size = {0, 1}`;
- `srcA_reg = {0, 1, 31, 63, 95}` (documented supported-GPR boundaries);
- `opsel = {4, 5}` (add/multiply); and
- packed immediate fields `imm_mant = {0, 1, 7}`, `imm_exp = {8, 11, 15}`,
  `imm_sign = {0, 1}`, with `imm_flag = 1`.

All excluded modifier fields are held to the descriptor's required zero values.
The generator requires exactly 1,440 unique semantic vectors. Each must
assemble, decode as `falu2i` without ambiguity, reassemble byte-identically,
preserve every semantic field, and preserve all fixed/match bits. It also
requires a decoded length of six bytes. Any failure, duplicate encoding,
unexpected descriptor, missing field, changed field, or nonzero residual byte
is a stop; no descriptor is changed in this experiment.

## Evidence and clean boundary

Inputs are only committed repository-authored `tools/agx-isa/isadb.py`,
`roundtrip_test.py`, `db.json`, and the authored analyzer below. The analyzer
first runs the existing central round-trip test, then emits append-only JSON
under `raw/`. It does not invoke Metal, inspect compiled output, or contact any
Apple implementation.

This result can establish codec/property-vector coverage for the bounded
semantic subset only. It cannot establish arbitrary modifier legality,
high-destination falu2 forms, hardware execution of newly generated bytes,
Apple compiler behavior, container ABI, or all-P0.6 closure.

Clean-room provenance: STRUCTURAL / OWN-SHADER-derived repository evidence.
Apple binary introspection: NONE.
