# EXP-0069 pre-registration — FALU2I modifier-codec vectors

This repository-only structural experiment addresses the P0.6 property-vector
coverage gap left by EXP-0060. It must be committed before its analyzer is run.
It will inspect only committed repository ISA inputs and will not build or run
Metal, open Apple binaries, compiled shader bytes, helper data, or BO payloads.

## Question

For a fixed valid `falu2i` semantic operand tuple, do all representable values
of the descriptor's currently non-semantic `opflags` (4 bits), `ctrl_lo` (7
bits), and `mods` (8 bits) fields assemble, decode as `falu2i`, and byte-round
trip without aliasing? The finite domain is 16 × 128 × 256 = 524,288 vectors.

This can establish only a structural codec property for the pinned descriptor.
It cannot assign any modifier meaning, prove generated bytes execute, establish
a general emitter or NIR lowering, or make native, M4, or A18 claims.

## Required capture gate

Before invoking the analyzer, it must write `raw/run01/00_inputs.json` with
the current Git revision and SHA-256 hashes for this plan, the analyzer,
`tools/agx-isa/isadb.py`, `roundtrip_test.py`, and `db.json`. The analyzer must
run the central round-trip test with a 30-second timeout, retain a closed JSON
report only, and fail if any vector aliases, changes mnemonic/length, or fails
byte round-trip. A later verifier must bind every input hash to Git blobs at
the captured revision and recompute the entire vector digest.

Any missing capture field, non-regular path, extra artifact, or analyzer
failure is a preserved stop, never a reconstructed result.
