# EXP-0115 -- M4 control-flow & SIMD: closing EXP-0104's seven deferred items

**Target: local Apple M4 (G16G) only.** No A18 Pro/G17P claim anywhere. No M5 claim.

## Question

`experiments/EXP-0104-m4-controlflow-simd/RESULTS.md` answered its 13 pre-registered
CF-*/SIMD-* items but explicitly deferred seven follow-ups (see its "Deferred"
section). This experiment closes all seven:

1. Exact branch-reach fault/silent-zero/correct boundary map (both directions).
2. Exact CF-03 nesting ceiling (push `ifnest`/`loopnest1`/a new bounded-work
   divergent `loopnestD2` until they actually break).
3. What `icmp_pred.dst_pred=1` (and the sibling `if_push_pred.pred` field) addresses.
4. Whether the static/immediate-index shuffle forms behave like the dynamic forms.
5. The full vote family under discard + the EXP-0104 popcount 16->24 puzzle.
6. Fragment-stage SIMD width sweep (EXP-0104 covered compute only).
7. Whether `simdgroup_barrier` is genuinely a no-op or just untested-into-mattering.

## Method

Own-authored MSL (`kernels/*.metal`, `kernels/deep/*.metal` machine-generated by
`harness/gen_deep_kernels.py`) compiled via this experiment's own `work/bin/{shdump,
agxrun,agxrender,agxparse.py}` builds of the read-only `tools/shdump`/`tools/agxtest`
sources, dispatched/spliced via `tools/agxtest/agxtest.py` (read-only), tokenized via
`tools/agx-isa/agxisa.py` (read-only). Every out-of-range/boundary value tested is
**independently constructed by direct byte splice**, not merely observed from
compiler output, per this experiment's directive. See `PRE_REGISTRATION.md` for the
full per-item hypothesis, falsifier, and frozen case list; `CAPTURE_CONTRACT.json` for
the pinned revision and blob hashes.

## Reproduce

```sh
cd experiments/EXP-0115-m4-controlflow-simd-deferred
clang -fobjc-arc -framework Metal -framework Foundation -O2 -o work/bin/shdump ../../tools/shdump/shdump.m
clang -fobjc-arc -framework Metal -framework Foundation -O2 -o work/bin/agxrun ../../tools/agxtest/agxrun.m
clang -fobjc-arc -framework Metal -framework Foundation -O2 -o work/bin/agxrender ../../tools/agxtest/agxrender.m
cp ../../tools/shdump/agxparse.py work/bin/agxparse.py
python3 harness/gen_deep_kernels.py kernels/deep

python3 harness/verify.py --selftest
python3 harness/verify.py --smoke
python3 harness/run.py --run-id m4_20260828_run01
python3 harness/run.py --run-id m4_20260828_run02
python3 harness/verify.py --seqtest
python3 harness/verify.py --captured m4_20260828_run01 m4_20260828_run02
python3 analysis/report.py
```
