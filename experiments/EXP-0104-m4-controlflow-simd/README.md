# EXP-0104 — M4 control-flow / execution-mask & SIMD-quad semantics

## Question

Answer the 13-item **CF-\*** (control flow / execution masks) and **SIMD-\***
(subgroups/quad ops) clusters of `APPLE9_RE_IMPLEMENTATION_GAPS.md` Part II, on
the local M4/G16G, with real hardware execution evidence (not compile-only
census) wherever the finite-resource mandate requires it: the execution-mask/
reconvergence model a compiler must emit (push/pop/branch sub-ops of the
`0x0f` family, nesting depth limits, branch reach), and subgroup/quad
semantics (width, ballot mapping, shuffle index range, scans under
divergence, quad geometry, barrier no-op-ness, helper-lane behavior).

See `PRE_REGISTRATION.md` for the exact per-item wording, hypotheses, and
coverage decisions (all 13 items COVERED; a few explicit narrower-scope notes
where the full ideal test was out of budget — e.g. fragment-stage width sweep,
full vote-family-under-discard).

## Method

- `kernels/cf_nest.metal` (generated by `harness/gen_cf_kernels.py`, frozen
  depths in `harness/matrix.py`) — nested if/return and nested-loop depth
  sweeps.
- `kernels/cf_misc.metal` — predicate-file, divergent-return, branch-reach,
  and additional if/else shape kernels.
- `kernels/simd_misc.metal` — width, ballot, shuffle-index, scan-divergence,
  quad-xor, `simdgroup_barrier` kernels.
- `kernels/frag_misc.metal` — fragment-stage quad-geometry and helper-lane
  vote kernels (rendered via `tools/shdump --render` + `tools/agxtest
  agxrender`, pixel-color readback only).
- `harness/matrix.py` — the frozen 92-case matrix (13 items + the
  branch-reach sub-question), each case's exact inputs and Python-computed
  host oracle.
- `harness/run.py` — executes every case as its own subprocess (compile via
  `shdump`, splice/run via `agxtest.py`/`agxrun`, or render via `agxrender`),
  hard-timeout-protected, appending gated/nongated JSONL records immediately.
- `harness/verify.py` — the five standing gates (`--selftest`, `--seqtest`,
  `--smoke`, `--captured RUN1 RUN2`).

## Commands (reproduction)

```sh
# build the read-only tools locally (never committed; work/bin/ is gitignored)
clang -fobjc-arc -framework Metal -framework Foundation -O2 -o work/bin/shdump ../../tools/shdump/shdump.m
clang -fobjc-arc -framework Metal -framework Foundation -O2 -o work/bin/agxrun ../../tools/agxtest/agxrun.m
clang -fobjc-arc -framework Metal -framework Foundation -O2 -o work/bin/agxrender ../../tools/agxtest/agxrender.m
cp ../../tools/shdump/agxparse.py work/bin/agxparse.py

# (re)generate the CF nesting-depth kernel source (deterministic given the depth lists)
python3 harness/gen_cf_kernels.py kernels/cf_nest.metal

# standing gates
python3 harness/verify.py --selftest
python3 harness/verify.py --seqtest
python3 harness/verify.py --smoke

# the two frozen captures
python3 harness/run.py --run-id m4_20260827_run01
python3 harness/run.py --run-id m4_20260827_run02
python3 harness/verify.py --captured m4_20260827_run01 m4_20260827_run02

# regenerate the analysis report
python3 analysis/report.py
```
