# EXP-0221 — PRE-REGISTRATION (frozen before the first gated dispatch)

**Target:** Apple A18 Pro / **G17P** (`AGXAcceleratorG17P`, `applegpu_g17p`, 5 cores,
macOS 26.6, `Mac17,5`, Metal family Apple9) at `192.168.170.254`. **Nothing runs on the M4.**

**Clean-room category:** OWN-SHADER + HW-PROBE. Our own MSL carriers compiled through the
public runtime API; every executed instruction byte is generated by this experiment from a
pinned `db.json`. **No Apple binary is disassembled, decompiled or introspected, and no
field value is read off a compiled instruction — including our own carriers'.**

## 1. The question

EXP-0220 cleared Gate D for `falu2` and left three named blockers on the recipe dashboard
(`tools/agx-isa/dashboards.py`, dashboard 4, re-derived at EXP-0221 start: **2 of 166
`canonical-recipe-proven`**, 3 `generated-no-donor`, 13 `generated-point`):

| instruction | status | what holds it back |
|---|---|---|
| `device_store` | `generated-no-donor` | the **threadgroup address space** — 4 of 4 `space` bit-1 values FAULTED against a device buffer; plus `extmode >= 128`; plus nine fields SAMPLED rather than swept densely |
| `device_load` | `generated-no-donor` | `addr_mode`, `access_desc`, `reserved7`, `reserved13` have no emitter-grade label; `ld_format`, the index GPR, `space`, `elem_size`, `base_slot`, `dst_lo`, `dst_ext9` and `ldform_hi11` were each held at ONE value |
| `stop` | `generated-no-donor` | `stop.reserved` is a 24-bit field sampled at **73 of 16,777,216** values and labelled `untested` |

**Question.** For each of the three, can the remaining classes be *generated* — every byte
from a documented rule or a value this experiment measures on hardware — executed on G17P,
and their observable state predicted in advance, with **zero** fields taken from a
compiler-emitted donor and none read off a disassembled carrier?

## 2. Hypotheses and falsifiers

| # | Hypothesis | Refuter |
|---|---|---|
| H1 | No program in the matrix contains a field tagged `COPIED` or `CARRIER`. | any non-zero `COPIED`/`CARRIER` count in the ledger |
| H2 | EXP-0220's four `device_store.space` bit-1 FAULTS are a property of its CARRIER (no threadgroup allocation), not of the encoding: with a static tile declared, the same encodings execute. | any `space` value faulting on `carrier221.metal` that also faults on `carrier221_notg.metal` at the same rate |
| H3 | A generated threadgroup `device_store` at `idx_off = k` places its datum where a generated threadgroup `device_load` at `idx_off = 4k` finds it, **and at no other load offset**. | any 4× pair that fails to deliver, or any non-4× pair that delivers |
| H4 | `device_load.access_desc`, `.addr_mode`, `.reserved7`, `.reserved13` are inert over all 256 values on G17P (EXP-0141's M4 measurement, carried across as a hypothesis). | any value where the load's result is not the predicted `mem[j]` |
| H5 | For every other densely swept `device_load`/`device_store` field, G17P's accepted set equals EXP-0141's M4 accepted set, frozen verbatim in `work/frozen/e141_m4_accepted_sets.json`. | any value accepted on one target and not the other |
| H6 | `device_store.extmode`: even `v` with `v/2 <= 95` stores `r(v/2)` at the target address; **odd `v` stores `r((v-1)/2)` TWO BYTES LOW**. (Model read off EXP-0220's own committed run01 observations at 126..200 — a prior recorded observation, re-measured here with r0..r95 all carrying distinct codewords.) | any register/offset that disagrees |
| H7 | `stop.reserved` is inert over the swept 1,178 values except where body byte 0 is a control-flow leader (`0x0F`/`0x8F`, EXP-0206). Inertness means: the program HALTS — a `device_store` placed after the `stop` does not write. | a swept value where the post-stop tripwire writes, or where the pre-stop control does not |
| H8 | Run 01 (canonical order) and run 02 (shuffled) produce byte-identical programs per case and identical per-case buckets. | any program-hash or bucket disagreement |

## 3. Independent / controlled variables

Independent: the case matrix in `harness/cases221.py` (32 arms, **7,160 cases with
hazards**, 7,122 without). Controlled and held fixed: buffer contents, grid/threadgroup
(1/1), pinned `db.json`, pinned `isadb.py`, harness revision, poison word `0xDEADBEEF`,
codeword block `imem[900..1023] = 0x5A17C0DE ^ (n * 0x01010101)`. **Carrier is a declared
variable with exactly two levels:** `carrier221.metal` (16,384 bytes of static threadgroup
memory) and `carrier221_notg.metal` (identical minus that allocation).

## 4. Gate mapping

* **Gate A** — per case, per instruction: the bytes the caller asked for are the bytes at
  that offset in the dispatched program (`dispatched_bytes_verified` re-reads the spliced
  archive from disk), and an INDEPENDENT bit-extraction decode (`decode_fields_as`, which
  does not use the length rule and is not `assemble`'s inverse-by-construction) returns the
  requested values. **§3z does not apply as a precondition:** no offset here is
  signature-derived — every instruction boundary is known because we generated it. The
  whole-program tokenizer walk is still run and its disagreements RECORDED as db.json
  findings for the orchestrator.
* **Gate B** — `ctl_baseline`, `ctl_norun`, three `ctl_move_*`; `ctl_tripwire_pre` (arm S's
  post-stop store, moved BEFORE the stop, must write — `stop` has no observable of its own
  and an inertness verdict on its body without this is a check that cannot fail); and
  `tg_ctl_device` (arm T's sixteen-register read-back bank, exercised on the DEVICE side
  where the answer is known). A failed control makes its arm `carrier-undecidable`.
* **Gate C** — every case carries a `predicted_bucket` chosen before the run
  (`exact` / `corrupt` / `refute` / `measure`) plus, for arm T, a **boolean**
  `expect_codeword`, because there the measurement is "did the datum arrive", not a byte
  map. Observations are classified `exact / wrong / no_write / stray / unpredicted / fault /
  hang / measurement_failure`.
* **Gate D** — the `RULE` / `FREE` / `CARRIER` / `COPIED` ledger over every field of every
  instruction of every program, plus §7's enumerated copied-region list.
* **Gate E** — two clean G17P runs on `carrier221.metal`, `run01` canonical and `run02`
  shuffled (`--order shuffle --seed 221`), plus a third capture on `carrier221_notg.metal`
  for H2; `harness/quietsample.py` measures the machine quiet throughout and `recoveryCount`
  is sampled before and after each.

## 5. Stopping rule and hazard budget

Every 8-bit domain named in §2 is swept densely (256/256), `st_format_ext` 128/128,
`st_desc_hi` 64/64, `ld_format` 64/64, `ldform_hi11` 64/64, `dst_ext9` 128/128, `dst_lo`
4/4. `stop.reserved` is swept over a **structured 1,178-value** set of its 16,777,216:
all 24 single-bit values and their complements, 0/1/2/3 and the all-ones neighbourhood,
**body byte 0 dense 0..255 twice** (with the other two bytes 0 and 0x5A5A), body byte 1
dense, body byte 2 dense, and a 128-value deterministic CRC-32 sample. **This is not a dense
sweep of a 24-bit field and is not reported as one.**

**Hang budget: 24 per run**, after which the run stops and records why. Declared hazards,
dispatched only with `--hazard`: `index_reg & 0x7F` in {96,97,100,111,112,120,127} on both
load and store (EXP-0141/EXP-0092 faults), `device_store.extmode >= 252` (EXP-0112 r126/r127
faults), and `stop.reserved & 0xFF` in {0x0F, 0x8F} (EXP-0206 control-flow leaders).

## 6. DISCLOSED PRE-FREEZE PILOT

`harness/tgpilot.py` stages 1 and 4..9 and a `--arms CTL --limit 20` smoke ran under
`work/pilot/` on the neo BEFORE this document was frozen. **They are disclosed, not
evidence**; every claim they suggested is re-measured inside the frozen matrix. What they
established, and what they did not:

1. **The new carrier works.** `carrier221.metal` compiles; `_agc.main` is 3,666 bytes; the
   S0 slot probe reproduces `slot 0 → out, 1 → mem, 2 → imem, 3..7 → none`.
2. **The arm-S tripwire has detection power.** The same store reads WRITTEN before the
   `stop` and NOT WRITTEN after it, in the same program shape.
3. **With a tile declared, threadgroup-space stores stop faulting.** 1,744 pilot dispatches
   sweeping the store's every descriptor byte with `space` bit 1 set returned `STATUS OK`
   0 faults, and never dirtied a device buffer. H2 re-measures this against the control
   carrier.
4. **The address law (H3).** Stage 6: `store_off → load_off` delivered the codeword at
   (0,0), (1,4), (2,8), (4,16), (8,32) and at NO other tested pair, including six pairs where
   the two offsets were equal. This is the 16-byte store unit versus 4-byte load unit
   EXP-0100 measured on M4 by splicing compiler-emitted threadgroup accesses; here it is
   measured on G17P from bytes we generated.
5. **The round trip is NOT SHAPE-INDEPENDENT, and this experiment therefore does NOT claim a
   threadgroup recipe.** It fires inside a 16-entry load bank and not for a single load
   carrying the identical descriptor; which bank slot fires moves with the OTHER loads'
   `elem_size` and with the destination registers; a 3,336-case single-reader sweep
   (stage 9) returned ZERO round trips at descriptors that had just delivered. Arm T4
   records that dependence as the finding it is. **`device_store` is pre-registered to stay
   `generated-no-donor`; no `n_unmeasured = 0` record will be written for it.**
6. Stage 8 is retained as a worked example of a **reader that cannot come out the other
   way**: scoring "any of sixteen bank readers delivered" reported 1,744 of 1,744 hits
   across store descriptors that cannot all be legal. Section 5a's pitfall, one level up.

## 7. THE COPIED-REGION LEDGER (Gate D's central requirement)

Generated: **every byte of `_agc.main`** — the whole region is overwritten from offset 0
with bytes this experiment assembled, padded to the carrier length with generated `mov_imm`
words that run after `stop` and are never reached.

NOT generated, exhaustively:

| region | why it is not an instruction field | how it is obtained |
|---|---|---|
| the Metal binary-archive container, AIR, metadata (buffer binding table, code length, threadgroup-memory declaration) | not instruction bytes; this experiment documents the ISA | produced by compiling OUR OWN MSL carriers through the public runtime API |
| `base_slot` (a real instruction field) | **not a donor**: EXP-0167 re-derived it by disassembling its own compiled carrier; that reads a required field off a compiler-emitted instruction | **arm S0 hardware probe**, repeated in every run of this experiment |
| the threadgroup `space` / `access_desc` / `elem_size` / `base_slot` candidates | **not read off any compiled threadgroup access** — not our carriers', not anyone's | **measured** by the disclosed pilot's round-trip probe and re-measured in arms T1–T4 |
| EXP-0141's M4 accepted sets | not values used to BUILD anything — they are the pre-registered PREDICTION each dense arm is scored against | extracted mechanically from EXP-0141's committed `raw/*/sweep.jsonl` into `work/frozen/e141_m4_accepted_sets.json` |

`CARRIER` and `COPIED` are retained as ledger classes so the record can prove they are
empty. **Expected: 0 of each, over every field of every instruction of every program.**

## 9. What this experiment does NOT claim

* **No threadgroup recipe for `device_store`.** See §6.5. `device_store` stays
  `generated-no-donor` and this experiment writes no record that would move it.
* No label anywhere is changed or proposed as changed; `tools/agx-isa/`, `docs/` and
  `PROVENANCE.md` are not touched. `device_load` and `stop` cannot move on dashboard 4
  regardless of what is measured here, because that dashboard takes `max(stored, live)`
  unmeasured fields and the live count comes from `validation.json`, which only the
  orchestrator may edit. The evidence for those labels is produced here; the promotion is
  not ours to make.
* `stop.reserved` is SAMPLED, not swept: 1,178 of 16,777,216.
* Single-thread dispatch (grid 1, threadgroup 1). Nothing here speaks to cross-lane or
  cross-thread behaviour, including whether the threadgroup tile is shared as expected.
* `device_load` values outside EXP-0141's M4 accepted sets are predicted TRUTHFULLY and
  bucketed `corrupt`; what they actually do instead is recorded, not modelled.
