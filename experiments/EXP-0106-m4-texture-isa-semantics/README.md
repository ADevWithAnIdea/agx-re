# EXP-0106 — m4-texture-isa-semantics

Answers the **TEX-\*** cluster (28 items, Part II, `APPLE9_RE_IMPLEMENTATION_GAPS.md`) for
**DRV-TEX-01**. Full per-item coverage/deferral table: `PRE_REGISTRATION.md` §1. This experiment
freezes one coherent subset (families `b01`..`b09`) for new M4 hardware/compiler evidence; the
remaining items are closed by citation to EXP-0016/EXP-0034/EXP-0094/EXP-0095 or explicitly
deferred with a named successor.

Target: **local Apple M4 (G16G) only**, macOS 26.6.2 (25G82), Metal 4, public Metal API. Clean-room
category: **OWN-SHADER + HW-PROBE (+ PUBLIC** for the MSL specification API-surface checks in
`PRE_REGISTRATION.md`). No Apple binary was ever disassembled, decompiled, or introspected.

## Reproduction

```
python3 gen_contract.py                 # regenerate CAPTURE_CONTRACT.json (deterministic)
python3 kernels/gen_b07.py              # regenerate kernels/b07_65.metal (deterministic)
python3 make_manifest.py --write
python3 verify.py --selftest
python3 verify.py --seqtest
python3 make_manifest.py --check
python3 verify.py --preflight
python3 run.py --run-id m4-20260830-run01 --execute
python3 verify.py --between-runs
python3 run.py --run-id m4-20260830-run02 --execute

python3 make_manifest.py --write
python3 verify.py --selftest
python3 verify.py --captured
```

## Layout

- `PRE_REGISTRATION.md` — all 28 TEX-\* items, per-item coverage/deferral decision, falsifiable
  hypotheses for the frozen `b01`..`b09` families, and the successor spec for the deferred
  raw-descriptor-injection items (TEX-26/27/28).
- `CAPTURE_CONTRACT.json` — the frozen, hash-pinned case list (`gen_contract.py` generates it
  deterministically from the case definitions in that script).
- `kernels/tex_isa.metal` — the main authored MSL kernel file (b02/b04/b05/b06/b08/b09).
  `kernels/b07_65.metal` (generated by `kernels/gen_b07.py`), `kernels/b04_level_minlod_fail.metal`,
  `kernels/b04_gather_minlod_fail.metal`, `kernels/b08_sampler17_fail.metal` — small
  isolated files whose entire purpose is a CONTRACTED compile-time rejection.
- `harness/probe.m` — the public-Metal-API-only harness (one process per case). Independently
  re-authored from this project's own EXP-0095 architecture.
- `analysis/pilot/explore.m` — NON-RECORDED pre-freeze exploration (determines failure MODE —
  exception vs. hard abort vs. compiler crash — for boundary cases, before any value entered
  `CAPTURE_CONTRACT.json`; not itself evidence, see `PRE_REGISTRATION.md` and `RESULTS.md`).
- `analysis/analysis.py` — derived, byte-exact analysis (per-case verdict + the two b09
  cross-checks described in that file's header).
- `run.py` / `verify.py` / `make_manifest.py` — the standard capture/gate/manifest tooling
  (independently re-authored from the EXP-0079/EXP-0083/EXP-0095 pattern).
- `raw/m4-20260830-run01/`, `raw/m4-20260830-run02/` — the two contracted capture runs.
